# StreetReady

Gamified investment-banking interview prep: technical study tracks, daily games, target-bank readiness, and a finance news / deals briefing.

## First release

- Daily Desk with streak, XP, smart review, and personalized next actions
- Study tracks covering accounting, valuation, DCF, M&A, LBO, and fit
- Games Arcade with a playable Multiple Match puzzle and interview drill modal
- My Banks readiness cards for Moelis, Stifel, and Jefferies
- Markets & Deals briefing with source-link architecture and industry filters

## Finance information standards

The live version should use linked journalism for discovery and primary sources to verify material deal details. The interface is designed to surface concise original summaries and outbound source links, rather than copy full articles.

## Run locally

Open `index.html` in a browser. No dependencies or build step are required for this first static prototype.
